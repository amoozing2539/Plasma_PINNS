# Plasma_PINNS
Attempts on reconstructing EM fields with sparse measurements in a variety of plasma wave modes.

Langmuir.ipynb explores the problem of reconstructing warm Langmuir Wave dynamcis (a purely electrostatic plasma wave) using only sparse electric potential measurements. 

PINN_XWave_DDP similarly explores the problem of reconstructing cold x-wave dynamics (electromagnetic plasma wave) using sparse electric potentila and magnetic flux measurements. We use distributed data parallel (DDP) to accelerate training.
